# Activacion WinPro — Sistema de Inventario de Licencias Windows 11 Pro

Sistema web autónomo y seguro para la gestión, control e inventario de licencias Windows 11 Pro.

---

## 🚀 Características Principales

### 👨‍🔧 Vista para Técnicos
- Interfaz limpia y directa, sin distracciones.
- Visualización del conteo de licencias instaladas y dañadas.
- Copiado de comando de activación con un solo toque:
  ```cmd
  slmgr -ipk XXXXX-XXXXX-XXXXX-XXXXX-XXXXX
  ```
- Botones de acción rápida: **Instalada**, **Probar** y **Dañada**.

### 🛡️ Panel de Administración
- Búsqueda avanzada de licencias y filtro por estados.
- Reportes formales para WhatsApp y proveedores de garantía.
- Gestión de usuarios y control de acceso por PIN.
- Importación masiva inteligente y exportación a CSV.

---

## 💻 Ejecución Local
- Abre el archivo `index.html` directamente en cualquier navegador web o ejecuta el servidor local con `server.ps1`.
- Sincroniza tus cambios a GitHub haciendo doble clic en `subir-github.bat`.
